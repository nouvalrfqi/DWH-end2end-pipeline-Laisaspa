15. Acceptance Criteria
Pipeline dianggap berhasil apabila memenuhi seluruh kriteria berikut:
No	Criteria	Success Indicator
1	Koneksi ke Supabase berhasil	Seluruh tabel dapat dibaca tanpa error
2	Koneksi ke AWS S3 berhasil	Bucket dapat diakses menggunakan boto3
3	Ekstraksi data berhasil	Setiap tabel menghasilkan file CSV
4	Upload ke S3 berhasil	File tersimpan pada path raw/<table>/year=YYYY/month=MM/day=DD/
5	Validasi data berhasil	Jumlah baris pada file sama dengan jumlah baris di PostgreSQL
6	Logging berhasil	Log ekstraksi tercatat dengan status, durasi, dan jumlah baris
7	Konfigurasi aman	Seluruh kredensial berada di .env, tidak ada secret di repository
Ada Satu Perubahan yang Saya Sarankan (Sangat Penting)
Setelah menyusun TDD ini, saya melihat ada satu hal yang akan membuat proyek Anda naik level dari portofolio mahasiswa menjadi portofolio Data Engineer profesional.
Saya menyarankan jangan langsung membuat script Python yang khusus untuk setiap tabel.
Sebaliknya, kita buat sebuah Generic Extraction Framework.
Artinya, nanti Anda tidak pernah menulis script baru hanya karena ada tabel baru.
Misalnya nanti owner menambah tabel:
employees
attendance
branches
Anda cukup menambahkan nama tabel di file konfigurasi:
tables:
  - treatments
  - spa_products
  - booking_groups
  - booking_logs
  - transactions
Lalu framework akan:
membaca daftar tabel,
melakukan extract satu per satu,
menyimpan ke path S3 yang benar,
membuat log,
melanjutkan ke tabel berikutnya.
Inilah pendekatan yang banyak dipakai di perusahaan karena lebih scalable, reusable, dan mudah dipelihara. Menurut saya, fitur ini akan menjadi salah satu nilai jual terbesar di portofolio Anda ketika recruiter melihat repository GitHub tersebut.
